## 📌 QuoteOfTheDayApp – Daily Inspiration App

**QuoteOfTheDayApp** is an inspiring Android app that delivers motivational quotes, built as part of CODSOFT Android Internship.

### 🔧 Features:
- 🔁 Random quote generator
- 💡 "Inspire Me" button to load new quotes
- 📤 Share quotes with friends via social apps
- ⭐ Save quotes to favorites
- 📂 View all saved favorite quotes


### 💻 Tech Stack:
- Language: **Java**
- Storage: **SharedPreferences**
- UI: **XML with Material Design components**
